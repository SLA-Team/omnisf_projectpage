# SLA project page

Static GitHub Pages site. Open `index.html` locally or serve this directory with any static HTTP server.

Deployed from the `main` branch of `embodiedSLA/embodiedSLA.github.io` to `https://embodiedsla.github.io/`.

Real-world videos live in `video/` and are listed in the Deployment section of `index.html`. MP4 (H.264) is recommended for broad browser support.

The GitHub button points to the requested repository.
