# Spatial Forcing++ project page

Static GitHub Pages site. Open `index.html` locally or serve this directory with any static HTTP server.

This repository is intended for `Chowzy069/omnisf_projectpage`. If GitHub Pages is enabled from the root of `main`, its URL is `https://chowzy069.github.io/omnisf_projectpage/`. The previously requested `https://spatial-forcing-plus.github.io/` requires a separate GitHub account or organization named `spatial-forcing-plus` and its matching Pages repository.

Seven demonstration slots are defined in `index.html` and `script.js`. When videos arrive, put the files in `assets/videos/`, then update each card's `data-src`, title, and description. MP4 (H.264) is recommended for broad browser support.

arXiv, Hugging Face, and author profile links intentionally remain disabled until URLs are supplied. The GitHub button points to the requested repository.
